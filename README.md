# 🏥 Hospital Management System (C Project)

**Hospital Management System in C** is a menu-driven, role-based project using file handling. It provides separate views for Patient, Doctor, Worker, and Admin with features like patient & doctor management, appointment handling, billing, and persistent data storage without using a database.

---

## 🚀 Features
- Role-based access (Patient, Doctor, Worker, Admin)
- Patient management (add, view, update, delete)
- Doctor management and assignments
- Appointment handling
- Billing system
- File-based data storage (`.dat` files)
- Menu-driven console interface

---

## 🛠 Technologies Used
- C Programming Language  
- File Handling  
- Structures  
- Switch-case and functions  

---

## ▶ How to Run
```bash
gcc hospital.c -o hospital
./hospital
